# Campus Connect

Campus Connect is a college event management system that helps students discover events, organizers manage them, and admins approve events and generate certificates.

## Features

- Student, organizer, and admin roles
- Event creation and approval workflow
- Student event registration
- Attendance management
- Certificate generation and download
- Secure authentication using JWT

## Tech Stack

- **Frontend:** React, Bootstrap
- **Backend:** Java, Spring Boot, Spring Security, JPA
- **Database:** MySQL

## Run Locally

```bash
# Backend
cd campus-connect-backend
mvn spring-boot:run

# Frontend
cd campus-connect-frontend
npm install
npm start
